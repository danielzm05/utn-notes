En [[1. Instrucciones|Assembler]] tenemos **dos tipos de instrucciones de salto**:

### Incondicionales
Es una única instrucción llamada `JUMP` que ejecuta el salto **siempre**, sin evaluar ninguna condición.

![[3. Instrucciones de salto.png]]


### Condicionales
En este caso las instrucciones condicionales **se fija que un flag cumpla con determinado** estado para realizar el salto:

> Se suelen usar después de una instrucción de comparación (`CMP`) o de resta (`SUB`).

- `JZ` Se fija que el flag `Z=1` para hacer el salto.
- `JNZ` Se fija que el flag `Z=0` para hacer el salto.

- `JC` Se fija que el flag `C=1` para hacer el salto.
- `JNC` Se fija que el flag `C=0` para hacer el salto.

###### Saltos para Comparaciones con Signo

- `JL / JNGE`  Jump if Less (SF ≠ OF)
    
- `JLE / JNG` Jump if Less or Equal (ZF=1 o SF≠OF)
    
- `JG / JNLE` Jump if Greater (ZF=0 y SF=OF)
    
- `JGE / JNL` Jump if Greater or Equal (SF=OF)
    

#### Saltos para Comparaciones sin Signo


- `JB / JNAE` Jump if Below (CF=1)
    
- `JBE / JNA` Jump if Below or Equal (CF=1 o ZF=1)
    
- `JA / JNBE` Jump if Above (CF=0 y ZF=0)
    
- `JAE / JNB` Jump if Above or Equal (CF=0)

**Ejemplo:**

```
MOV AX, 5
CMP AX, 3     ; Compara AX con 3
JG Mayor      ; Si AX > 3 (con signo), salta a "Mayor"
JMP Fin       ; Sino, sigue en "Fin"

Mayor:
  MOV BX, 1
  JMP Fin

Fin:

```
