Se conoce de cada alumno de un curso los siguientes datos: legajo (8digitos) y las notas de 2 parciales (0..10), que finaliza con un legajo negativo.  
Se pide desarrollar un programa que ingrese los datos de los alumnos por teclado y grabe un archivo binario CURSO.BIN con una línea por cada alumno, con el número de legajo y su  
promedio (real).

```c++
#include <iostream>
using namespace std;
struct Alumno{
  int legajo;
  int promedio;
};

int main(){
  FILE* f = fopen("CURSO.bin", "wb+");
  Alumno al;
  int nota1, nota2;
  cout<<"Ingrese legajo del alumno:";
  cin>> al.legajo;
  
  while (al.legajo>=0)
  {
    cout << "Ingrese nota del primer parcial: ";
    cin >> nota1;
    cout << "Ingrese nota del segundo parcial: ";
    cin >> nota2;
    cout<<"Ingrese legajo del alumno:";
    cin>> al.legajo;
    al.promedio = (nota1 + nota2) / 2;
    fwrite(&al, sizeof(Alumno), 1, f);
  }
  
  fclose(f);
  return 0;
}
```
