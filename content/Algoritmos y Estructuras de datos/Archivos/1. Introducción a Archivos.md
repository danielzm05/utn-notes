## ¿Qué es un archivo binario?

Un **archivo binario** es un fichero que guarda datos en la misma representación que se almacena en memoria (bytes), sin conversión a texto legible. En C/C++ se usan para almacenar estructuras, números y cualquier dato en formato compacto y eficiente. A diferencia de un archivo de texto, no se puede leer correctamente con un editor de texto si contiene datos estructurados o números en formato binario.

**Ventajas:** menor tamaño, lectura/escritura más rápida, conservación exacta de la representación de tipos.

**Desventajas:** no es legible por humanos y hay que controlar la portabilidad entre arquitecturas (endianness, tamaños de tipos).

---

## Operar con archivos binarios

### Abrir un archivo

```c++
FILE* f = fopen("miArchivo.bin", "rb");
```

**Primer parámetro:** ruta y nombre del archivo.

**Segundo parámetro (modo):** string que indica cómo abrir el archivo. Los modos más usados para binarios son:

- `rb` : abrir para **lectura** en modo binario. El archivo **debe existir**; si no existe `fopen` devuelve `NULL`.
- `wb` : abrir para **escritura** en modo binario. Si no existe, se **crea**; si existe, se **trunca** (se borra el contenido previo).
- `ab` : abrir para **escritura en modo append** (agregar al final) en binario.
- `rb+` o `r+b` : abrir para **lectura y escritura** en binario; el archivo **debe existir**.
- `wb+` or `w+b` : abrir para **lectura y escritura**; si no existe se crea, si existe se borra (trunca).
- `ab+` : abrir para lectura y escritura, con escritura siempre al final (append).
    

> **Diferencia `rb` vs `rb+`:** `rb` permite solamente **lectura**; `rb+` permite **lectura y escritura** sin truncar el archivo (pero el fichero debe existir). Si necesitas modificar registros en sitio, usa `rb+`.

---

#### Cerrar archivo

```c++
fclose(f);
```

`fclose` cierra el archivo y libera recursos asociados (descriptor de archivo y buffers). Siempre debes llamar a `fclose` para evitar pérdidas de datos.

---

#### Liberar el buffer

```c++
fflush(f);
```

`fflush` fuerza la escritura del buffer en disco para el `FILE*` dado. Se usa para asegurarse de que los datos pendientes en memoria se guarden inmediatamente.

> [!question] **¿Qué es el buffer?**
> 
> El _buffer_ es una región de memoria intermedia donde la biblioteca estándar guarda datos antes de escribirlos definitivamente en disco o antes de entregarlos al programa al leer. El uso de buffers mejora el rendimiento al reducir el número de operaciones de E/S físicas.

---

#### Escribir en el archivo

```c++
size_t fwrite(const void* ptr, size_t size, size_t nmemb, FILE* stream);
```

**Parámetros:**

- `ptr` : puntero al bloque de memoria que contiene los datos a escribir.
    
- `size` : tamaño en bytes de cada elemento.
    
- `nmemb` : número de elementos a escribir (cada uno de `size` bytes).
    
- `stream` : puntero al `FILE` abierto (por ejemplo, `f`).
    

**Valor de retorno:** número de elementos escritos (no bytes). Si es distinto de `nmemb`, ocurrió un error o se llegó al final del dispositivo.

---

> [!question] **¿Qué es `sizeof()`?**
> 
> `sizeof(type)` o `sizeof(expr)` devuelve en tiempo de compilación (en la mayoría de los casos) el tamaño en bytes del tipo o expresión proporcionada. Ejemplos:
> 
> ```c++
> sizeof(int)     // normalmente 4 en sistemas modernos
> sizeof(double)  // normalmente 8
> sizeof(miStruct)
> ```

---

#### Leer Archivo

```c++
size_t fread(void* ptr, size_t size, size_t nmemb, FILE* stream);
```

**Parámetros:** los análogos a `fwrite`:

- `ptr` : puntero al buffer donde se almacenarán los datos leídos.
- `size` : tamaño en bytes de cada elemento.
- `nmemb` : número de elementos a leer.
- `stream` : puntero al `FILE` abierto.
    

**Valor de retorno:** número de elementos leídos. Cuando devuelve `0`, no hay más elementos (o hubo error).

---

#### `fseek()`

```c++
int fseek(FILE* stream, long offset, int whence);
```

Mueve el indicador de posición dentro del archivo.

**Parámetros:**

- `stream`: el archivo.
    
- `offset`: desplazamiento en bytes.
    
- `whence`: punto de referencia. Valores posibles:
    
    - `SEEK_SET` : desde el **inicio** del archivo.
    - `SEEK_CUR` : desde la **posición actual**.
    - `SEEK_END` : desde el **final** del archivo.
        

**Valor de retorno:** `0` si tiene éxito, distinto de `0` si falla.

Ejemplo:

```c++
fseek(f, 0, SEEK_END); // posiciona al final
```

---

#### `ftell()`

```c++
long ftell(FILE* stream);
```

Devuelve la posición actual (en bytes) desde el inicio del archivo. Si ocurre un error devuelve `-1L`.

Ejemplo corto:

```c++
long pos = ftell(f);
if(pos != -1L) cout << "Pos actual: " << pos << endl;
```

### Función para la cantidad de registros 

```c++
int cantReg(FILE* f, int tamStruct){
    long regActual = ftell(f);
    fseek(f, 0, SEEK_END);
    long tamArch = ftell(f);

    int cant = 0;
    if (tamArch > 0 && tamStruct > 0)
        cant = (int)(tamArch / tamStruct);

    fseek(f, regActual, SEEK_SET);
    return cant;
}

```

## Guardar archivo en un vector (corrección)

```c++
Venta vec[cantidad];

fseek(f, 0, SEEK_SET);
// fread(buffer, sizeof(tipo), cantidad, archivo)
fread(vec, sizeof(Venta), cantidad, f);
```

> **Corrección:** en tu versión se usó `sizeof(ventas)`. Debe ser `sizeof(Venta)` (el tipo) o `sizeof(vec[0])`.

## Leer múltiples líneas

#### Método 1: usando `feof()`

`feof(stream)` devuelve distinto de cero si el indicador EOF del stream ya está marcado (es decir, se intentó leer más allá del final). Usar `feof` **solamente** como condición del `while` puede provocar duplicados o intentos de lectura extra; la práctica recomendada es combinar con la lectura real (`fread`).

Ejemplo correcto con `feof` (no recomendado como única condición):

```c++
Venta leer;

fseek(f, 0, SEEK_SET);
while(!feof(f)){
    if(fread(&leer, sizeof(Venta), 1, f) == 1){
        // procesar
        cout << "idsuc:" << leer.idSucursal << " cantidad:" << leer.cantidadVendida << endl;
    }
}
```

#### Método 2: usando el valor retornado por `fread` (recomendado)

`fread` devuelve el número de elementos leídos. Si pedimos 1 elemento y `fread` devuelve 1, fue una lectura correcta; si devuelve 0, no hay más datos (o hubo error).

```c++
Venta leer;

fseek(f, 0, SEEK_SET);
cout << "Modelo 2 con una lectura" << endl;
while(fread(&leer, sizeof(Venta), 1, f) == 1){
    cout << "datos leidos: idsuc:" << leer.idSucursal
         << " cantidad:" << leer.cantidadVendida << endl;
}

fclose(f);
```

#### Ejemplo completo de programa (uso de todo lo visto)

Este ejemplo define una estructura `Venta`, escribe varias ventas a un archivo binario y luego muestra cómo leerlas, obtener la cantidad de registros y cargar el archivo en un vector.

```c++
#include <iostream>
#include <cstdio>
#include <cstring>
using namespace std;

struct Venta {
    int idSucursal;
    int cantidadVendida;
    char producto[40];
};

int cantReg(FILE* f, int tamStruct){
    long regActual = ftell(f);
    fseek(f, 0, SEEK_END);
    long tamArch = ftell(f);

    int cant = 0;
    if (tamArch > 0 && tamStruct > 0)
        cant = (int)(tamArch / tamStruct);

    fseek(f, regActual, SEEK_SET);
    return cant;
}

int main(){
    const char* nombre = "ventas.bin";

    // 1) Abrir archivo para escribir (crea/trunca)
    FILE* f = fopen(nombre, "wb");
    if(!f){
        perror("Error al crear archivo");
        return 1;
    }

    // 2) Preparar datos y escribir
    Venta v1 = {1, 10, "Manzanas"};
    Venta v2 = {1, 15, "Peras"};
    Venta v3 = {2, 20, "Naranjas"};

    fwrite(&v1, sizeof(Venta), 1, f);
    fwrite(&v2, sizeof(Venta), 1, f);
    fwrite(&v3, sizeof(Venta), 1, f);

    fflush(f); // asegurar escritura inmediata (opcional)
    fclose(f);

    // 3) Abrir para lectura
    f = fopen(nombre, "rb");
    if(!f){
        perror("Error al abrir archivo para lectura");
        return 1;
    }

    // 4) Cantidad de registros
    int cant = cantReg(f, sizeof(Venta));
    cout << "Cantidad de registros: " << cant << endl;

    // 5) Leer todos en memoria (vector dinámico)
    Venta* vec = new Venta[cant];
    fseek(f, 0, SEEK_SET);
    size_t leidos = fread(vec, sizeof(Venta), cant, f);
    cout << "Registros leidos en vector: " << leidos << endl;

    for(int i = 0; i < (int)leidos; ++i){
        cout << "Registro "<< i << ": suc:" << vec[i].idSucursal
             << " cant:" << vec[i].cantidadVendida
             << " prod:" << vec[i].producto << endl;
    }

    delete[] vec;
    fclose(f);
    return 0;
}
```
