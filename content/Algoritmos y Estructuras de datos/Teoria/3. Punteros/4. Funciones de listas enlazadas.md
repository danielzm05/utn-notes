### Buscar en la lista
Busca un valor, retornando la posición, en caso de encontrarlo o NULL en
caso que este no esté.

```c++
Nodo* buscar(Nodo* l, int v){
 Nodo* aux = l; 
 while( aux!=NULL && aux->info!=v ) {
  aux=aux->sig; } return aux;
```
