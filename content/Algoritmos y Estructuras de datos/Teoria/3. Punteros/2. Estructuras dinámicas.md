## Nodo
Un **nodo** es la pieza básica de estructuras dinámicas, contiene datos y un puntero a otro nodo.

```c++
struct Nodo {
    int info;       // información almacenada
    Nodo* sig;      // puntero al siguiente nodo
};
```


> [!quote] Un nodo es una estructura autorreferencia
> Se llama **autoreferenciada** porque tiene un campo que referencia a una **estructura de su mismo tipo**, lo que permite crear enlaces entre nodos y formar cadenas como listas, pilas, colas o árboles.

### Pilas

Una **pila** (stack) es una **estructura de datos lineal** que funciona con la regla **LIFO** (_Last In, First Out_). 

>El **último elemento** en entrar es el **primero en salir**.

La pila es un **puntero a un nodo** que me va a permitir **acceder a la información, agregar o sacar nodos.**
==Esta se debe inicializar SIEMPRE en `NULL`.==


#### Crear pila
```c++
struct Nodo {
    int info;       
    Nodo* sig;      
};

Nodo* pila=NULL;

```

#### Agregar nodo
```c++
void push(Nodo*& pila,int info){ 

nodo* p=new nodo(); // Reservamos espacio en memoria para crear el nodo 
p->info = info; // Cargar el valor dentro del nodo
p->sig = pila; //Cargar el puntero dentro del nodo (nodo siguiente)
pila=p; //Asignar el nuevo nodo a la pila 

return; 
}
```

#### Eliminar un nodo
```c++
int pop(Nodo*& pila){ 
	int aux; 
	Nodo* p=pila; 
	aux=p->info; 
	pila=p->sig; 
	delete p; 
	
	return aux; 
}
```

### Cola
Una **cola** (queue) es una **estructura de datos lineal** que funciona con la regla **FIFO** (_First In, First Out_):

> El **primer elemento** en entrar es el **primero en salir**.


#### Insertar en la cola

```c++
void queue(Nodo*& cfte,Nodo*& cfin, int info){ 
  Nodo* p=new Nodo(); //Crear nuevo nodo 

  p->info = info; 
  p->sig = NULL; 
  if(cfte==NULL){ 
    cfte=p; 
  } else {
  cfin->sig=p; 
  } 
  cfin = p; 
}
```

 
> [!tip] Si el frente es igual a `NULL` entonces la cola esta vacia.


#### Eliminar nodo

```c++
int unqueue(Nodo*& cfte,Nodo*& cfin) {
  int aux; 
  Nodo* p=cfte;
  aux=p->info; 
  cfte = p->sig;

  if(cfte==NULL) {
    cfin=NULL; 
  } 
  
  delete p; 
  return aux; 
}
```


**Ejemplo:**

```c++
#include <iostream>
using namespace std;

struct Nodo{
  int info;
  Nodo* sig;
};

void queue(Nodo*&, Nodo*&, int);
int unqueue(Nodo*&, Nodo*&);

int main(){
  Nodo* cfte = NULL;
  Nodo* cfin = NULL;

  queue(cfte, cfin, 20);
  queue(cfte, cfin, 30);
  queue(cfte, cfin, 40);

  while(cfte!=NULL){ 
    cout << unqueue(cfte, cfin)<<endl; //Imprimir hasta el final
  }
  return 0;
}
```
